Swarm Office — System Map

How ten agents, one chain-linked ledger, and a deterministic world produce verified work autonomously. Inspired by SwarmWorld (arXiv 2608.26081).

READ-ONLY

Initiative Scanner

Walks the real environment: TODO markers, duplicate notes, oversized files, stale reports. Finds work organically.

THE WORLD

Swarm Bench Ledger

Chain-linked artifacts (SHA-256). Deterministic evaluators stamp PASS/FAIL. Cognition proposes; the world disposes.

STIGMERGY

Staff Observe & Build

World state injected before every turn. Staff see what exists, fork via parent links, differentiate into roles.

REVIEW

Hermes Review

Staff proposals are staged, never self-applied. Hermes verifies, applies or rejects.

SYNC

Ecology Bridge

Bench state flows to every surface every 6h: office HTML, Memory Lane, Obsidian, cloud VM.

SURFACES

Where you watch

Claw3D 3D office (cloud), staff-office.html, Memory Lane, Obsidian vault, kanban board.

TOOLS

Staff Capability Layer

web_search, GitHub, email triage (read-only), own-desk notes, propose_code, escalate.

FOUNDER ONLY

Approval Boundary

Deletion, mass changes, secrets, financial scope. Everything reversible advances freely.
